1. État actuel — trois mécanismes qui ne se parlent pas

Chaque application a été équipée séparément, à des moments différents : Frontend utilise react-i18next mais seul le Footer est réellement traduit, dash a un dictionnaire fait main qui ne couvre que les pages de connexion, et bet-elearning est déjà sur Weglot (traduction automatique). Aucun des trois ne partage sa configuration avec les autres.

2. Proposition — un seul compte Weglot, multisite

Weglot traduit automatiquement tout le texte affiché à l'écran, sans avoir à extraire une clé par phrase — ce qui absorbe le volume de dash sans travail de développement par composant. Un plan multisite (à partir de Pro) permet de gérer les 3 sites sous un seul abonnement.
